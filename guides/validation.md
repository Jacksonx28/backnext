# BackNext — first validation pass

## Positioning

A creator shares a small menu of upcoming work. Fans back a request. The delivered link stays attached to its support history. The repeat loop is new request → support → delivered work → new request.

This is an adaptation of existing crowdfunding and audience-polling ideas, not a claim to have invented creator requests. Ko-fi already lets creators ask supporters what they want next: https://help.ko-fi.com/hc/en-us/articles/19068973151133-Create-a-Poll-on-Ko-fi . BackNext's proposed distinction is connecting request-level onchain contributions to the delivered result in one small workflow. Whether users prefer this remains untested.

A preliminary exact-name search found existing uses of BackNext, including a software listing and a developer handle. This is not trademark or domain clearance. Keep the name provisional for a hackathon prototype.

## Remaining product risks

- Token acquisition makes this a poor first product for ordinary fans unfamiliar with crypto. Start with existing WIF community creators.
- Creators can take support without delivering. State that backing is support and not a guaranteed purchase; show delivery history. Do not promise escrow/refunds.
- A goal is informational, not an automatic trigger. Support does not create ownership or investment returns.
- Contribution totals are not unique fan counts and can be dominated by a few wallets. Do not label them a democratic vote.
- Creator access, metadata durability, and cross-device shared state must be implemented before live launch.

## Deadline evidence

The contest page inspected on 2026-11-11 listed submission close as November 12, 2026, 17:30 UTC (18:30 Lagos), round one close November 14, and final close November 16. Entry requires working WIF use on Robinhood Chain, a visible repository, a demo video, and real transactions. Product must stay live through final close. https://worldisflat.fun/build/rules

## First user test

Ask 3–5 existing community members to explain what backing means, support one request in the demo, and find the delivered result without instructions. Ask one creator to supply three genuine requests and commit to delivering one. Record confusion and willingness to use it, not invented traction.
